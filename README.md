# CBL-16: Data driven estimation of police demand for resource allocation

This repository contains our two final models for scoring policing demand per LSOA (Lower layer
Super Output Area), sorting areas into priority tiers, and validating the score against realised
future demand.

## Contents

| Item | What it is |
|---|---|
| `london-final-light/` | **Final London model** (deployable). Self contained notebooks `phase1` to `phase6`, built from `data/`. |
| `england_final_light/` | **Final England model** (national, structural). Self contained notebooks `phase1` to `phase6`. |
| `data/` | Input data folder. The two small derived/auxiliary files are included; the large raw data is downloaded (see below). |

Both models use the same pipeline:

1. **Phase 1 - Ingestion:** read the raw police.uk crime, outcomes and (London) footfall data.
2. **Phase 2 - Feature engineering:** one row per LSOA. Harm weights come from the Cambridge Crime
   Harm Index 2026 (the weight values are embedded directly in the Phase 2 notebook).
3. **Phase 3 - Validation:** keep only features that pass a correlation and multicollinearity screen.
4. **Phase 4 - Risk index:** derive weights with Negative Binomial regression and a Random Forest,
   then combine the features into one 0 to 100 score.
5. **Phase 6 - Supervised tiering and validation:** build the score on the first 24 months, test
   whether it predicts the held out final 12 months (ROC / AUC), and set the four priority tiers
   from ROC cut points. This supervised tiering is what we use; it replaced an earlier clustering
   step.

The two models differ only in scope and features. London uses harm weighted crime, night time
radiance, employment deprivation and resolution rate. England leaves crime harm out and uses night
time radiance, resolution rate and employment deprivation, so it is a structural view of demand.

## The data folder

To keep the repository within GitHub size limits, the large raw data is **not** committed; only two
small files are included. Recreate `data/` as follows:

| Path | Included? | Source |
|---|---|---|
| `data/lsoa_nightlights_england.parquet` | yes (committed) | VIIRS night-time radiance, NASA Black Marble VNP46A4 2024 |
| `data/IoD-2025-custom_data_download-LSOA.csv` | yes (committed) | Indices of Deprivation 2025 (LSOA level) |
| `data/crimes/` | download | police.uk open data, April 2023 to March 2026: https://data.police.uk/data/ |
| `data/footfall/` | download | TfL station entry/exit counts (London only). Still ingested by London Phase 1/2 but **not used** as a feature see note below. |
| `data/temp-london/` | download | HadUK-Grid monthly temperature (used only in London Phase 1) |
| `data/LB_shp/` | download | London LSOA 2021 boundaries (ONS) |
| `data/Lower_layer_..._EW_...` | download | England and Wales LSOA 2021 boundaries (ONS) |

The Phase 1 output parquets are also not committed (they are large and are regenerated by Phase 1).

**Note on footfall.** The final London model uses night-time radiance instead of footfall, so `total_footfall` does not enter feature selection (Phase 3) and has no effect on the risk score or tiers. However, London's Phase 1 and Phase 2 notebooks still read and build the footfall data, so the `data/footfall/` download is required to run them without errors. The England model does not use or load footfall at all.

## How to reproduce

1. Populate `data/` as above.
2. Install: pandas, numpy, geopandas, xarray, scipy, scikit-learn, statsmodels, libpysal, esda,
   matplotlib, seaborn.
3. For each model, run the notebooks in order from `phase1_ingestion` through
   `phase6_supervised_validation`. Phase 1 regenerates the large parquets; the later phases produce
   the figures, tier tables and the supervised tiers.

## Key result (honest summary)

The composite index predicts next-year hotspots well (AUC about 0.92 for London, 0.83 for England),
but it does not beat a naive "use last year's crime" baseline (about 0.98) for raw volume. Its value
is the harm, equity and structural dimensions it adds. The Phase 6 tiers are validated: the share of
areas that truly became hotspots falls steadily from Tier 1 to Tier 4.
